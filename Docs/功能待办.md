# 功能待办

## TEAM-EDIT-001：队伍编辑界面后续接入

状态：待实现

### 当前进度

- 主菜单的队伍入口已经通过 `UIManager` 打开 `TeamEditView`。
- `TeamEditView` 负责创建队伍展示场景、切换主镜头，并在关闭时恢复现场。
- 四个角色位目前共用同一个角色选择面板；点击任意角色位可以打开面板，返回操作会优先关闭面板。
- 角色选择面板暂时复用 `ItemSlot` 作为角色图标占位，尚未接入角色数据和选择结果。

### 待处理

1. 点击角色位时记录目标队伍槽位，并把槽位上下文传给角色选择流程。
2. 将通用选择界面接入角色数据源，继续复用 `ItemSlot` 展示头像、选中态和不可用态。
3. 选择角色后回写目标槽位，并刷新队伍展示模型；补充替换、清空和重复角色约束。
4. 明确编辑中的临时队伍与已保存队伍的数据边界，再接入确认、取消和持久化。
5. 完善角色模型加载、站位、朝向和镜头构图，处理页面快速开关时的异步资源生命周期。
6. 确认通用选择界面最终采用 `TeamEditView` 内部面板还是独立 UI 栈；当前版本保持内部面板，不新增 `UIType`。
7. 补充主菜单进入、选择面板开关、页面返回和重复打开的 Play Mode 验证。

### 验收标准

- 点击不同角色位时，选择结果只更新对应槽位。
- 打开和关闭选择面板不会重复注册监听，也不会改变 `UIManager` 页面栈层级。
- 关闭队伍页面后，队伍展示实例被释放，进入页面前的主镜头状态被正确恢复。
- 连续进入和退出队伍页面时不残留模型、相机或异步加载任务。

### 恢复方式

后续任务中搜索或引用 `TEAM-EDIT-001`，从本记录继续。
